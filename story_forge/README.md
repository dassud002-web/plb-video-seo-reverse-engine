### 4. 20-Dimensional Story Genome
Every story is represented as a structured genome:
1. Core Premise & Title
2. Story World
3. Ensemble & Species
4. Relationship Dynamic
5. Setting & Location
6. Time Horizon
7. Catalyzing Object
8. Primary Goal
9. Motivation
10. Central Conflict
11. Obstacles & Complications
12. Narrative Escalation
13. Midpoint Turning Point
14. Climax / Decisive Encounter
15. Creative Twist
16. Comic / Emotional Payoff
17. Short-Form Hook (0-3s)
18. Loopability Mechanism
19. Tone & Resonance
20. Camera & Visual Perspective

### 5. 9-Dimensional Quality Engine & Ranking
Scores every story on:
- *Novelty (15%)*, *Hook Potency (15%)*, *Comedy Value (15%)*, *Emotional Value (10%)*, *Animal Appeal (15%)*, *Visual Potential (10%)*, *Short-Form Potential (10%)*, *Production Feasibility (10%)*.
- Quality Gate Cutoff: Composite Score $\ge 85.0$ / 100.
- Top 10, Top 50, Top 100 ranking filters.

### 6. 9-Part Production Pipeline Studio
Converts any selected story into a production package:
1. **15-Second Production Script** (Timestamps, Action, Foley, Audio cues)
2. **6-Shot Storyboard** (Hook, Setup, Escalation, Climax, Payoff, Loop)
3. **Hero Frame Specification** (Composition, lighting, palette, lens)
4. **Continuity Lock** (Morphology, environment lock, immutable traits)
5. **Seedance Prompt** (Optimized for Dreamina / Seedance video generation)
6. **Google Veo 2 Prompt** (High-fidelity cinematic text-to-video prompt)
7. **Audio Plan** (Foley requirements, comedic SFX, tempo, loop transition)
8. **Multi-Platform Captions** (TikTok, Instagram Reels, YouTube Shorts, FB Reels)
9. **Evidence-Based SEO Pack** (Primary topic, keyword, long-tails, hashtags, pinned comment)

## 🚀 How to Run

### 1. Launch Server (Port 5050)
```powershell
python story_forge/run_app.py
```
Or double-click:
```cmd
.\story_forge\run_app.bat
```

### 2. Access Web Interface
Open:
```
http://127.0.0.1:5050
```

*(Runs independently side-by-side with the PLB Video SEO Reverse Engine on port 5000).*
